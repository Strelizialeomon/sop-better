## 1. 病根（为什么改）

**原始 bug（turn-1）**：`/sop-init` 生成的 CLAUDE.md 把「起手新鲜度」埋了（py-script 实测）——根因是**标准块自己 authoring 成了指针**、不是生成机制 misfire。下面这个"戴皇冠 vs 进地窖"对比当初被读成"抽象蒸馏丢载重"，round-1/2 验证那是**误读**（见 ⚠️）：

- `media-ops/CLAUDE.md:8` 把「起手新鲜度」摆成 **§最高优先级第一节**，自带"为什么排第一"的生产安全论证。
- 抽象模板 `templates/agent-constraints.md:15` 把同一条埋成括号里小项，标题还叫"别全塞这"。
- **同一条规则，真项目里戴皇冠、蒸馏版里进地窖。**

> ⚠️ 自检修正（round-1 新眼睛）：freshness 这例子**没当初说的那么干净**。`agent-constraints.md:15` 那个括号是 exp-006 **故意的瘦内核**（情景规则挪去 on-demand doc、留指针，不是"蒸馏丢了"——full freshness 机制在 `issue-pr-workflow.md` 里没被埋）。media-ops 摆它第一节，是因为它是**项目级 always-loaded doc（不同海拔）+ 2人 git 协同 + 读生产**，风险画像本就高。所以这条只证明"**风险高时实例化该更显眼**"（turn-1 的精确结论），**不**证明"抽象必丢载重"。

系统性证据其实在**别处**：exp-012（挂错闸）/ exp-013（删除残留盲）是真·抽象件机制 misfire；更扎心的是 **media-ops 自己至今还带 S1·C1 + 缺 exp-011 受众闸 + 缺承重墙不豁免行**——这是「**回灌没传到位**」（exp-007续），不是"抽象 vs 具体"。治法仍可指向"具体母本 + 单一实例化源 + 机械漂移逮"，但**前提得诚实**：根问题里很大一块是回灌纪律、不是表示法（→ 见 §14 scope 决策）。

## 3. 架构（公约仍是唯一权威；母本是 templates/ 的重排+骨架、运行时只 copy）

```
templates/(已是当前母本·整份具体)  ──重排──→  master/( base + layer-* 按触发分层 )
media-ops(只取结构/海拔)           ──骨架──→   base/CLAUDE.md(crown freshness/风险轴)
   STANDARD §1 公约(抽象权威·不动) 仍是上位裁决       │
                                     /sop-init: copy层+填槽+按触发剪枝 ↓
                                     新项目 SOP  ←  /sop-audit 双向diff(已ship)接 master/
```

**win 在哪（右尺寸·验证后）**：今天 `/sop-init` **已经** copy 整块+填槽+按触发剪枝（SKILL step4，不是"现拼碎片"）。所以 win **不是**"消除运行时拼装"（基本已实现），而是：① **base 骨架 crown freshness/风险轴**（治原始 bug · **唯一硬价值**）；② templates/ → **trigger-layer 目录**（维护更清 + 单一 canonical 源）；③ audit 接已 ship 的双向 diff。**templates/ 内容是当前的、重排进 master/ 基本 verbatim**——非"3 源合成"。

## 4. 母本布局（三正交触发 = 三条整份层）

```
    issue模板 + label状态机(评估中/开发中/已完成 + 待业务确认)
  layer-collaborators/      # 触发:≥2个人      = templates/ 已拆好的双角色段(当前版) + media-ops 的 gh身份判定 + 角色命令
  layer-multiend/           # 触发:≥2个端      = taoxi-geo 抠:docs/contracts/(README+multiend-contracts) + 每端 <end>/CLAUDE.md
  layer-parallel-agents/    # 触发:真并行多agent = taoxi-geo 抠:worktree-isolation.md + coordination.md(6+1/消息总线/scope/coordination)
  SLOTS.md                  # 槽清单 + 清洗映射(哪些是项目肉、怎么填/删)
```

> 注（自检修正）：原说"旧 `templates/collaboration.md` 一份文件两触发共用 = exp-012 隐患"——**这是错的**。实读其头部：它**早已"两段独立触发、可只有其一"**，exp-012 就是那次解耦、已 ship。所以这里把两段**物理落成两份文件**只是布局选择，**不**关闭任何 exp-012 缺口（别当卖点）。phase 4 改 STANDARD §3「一份 collaboration.md 带对应段」措辞时对齐这个物理拆分即可。

**三触发自检**（必须各归各位）：
- taoxi-geo（单人·多端·并行）= base + multiend + parallel，**不要** collaborators ✅
- media-ops（2人·单端·串行）= base + collaborators，不要后两层 ✅
- 多端串行 = base + multiend，**不**背 worktree ✅

**escalate carve-out 端-agnostic（exp-009 · F7）**：§1.9 指针在 `layer-collaborators`（→业务方）和 `layer-parallel-agents/coordination.md`（→coord）**两层都落**，别只挂并行层——2人单端项目也会碰"owner 当面交办扩范围"。

**不变量**：每层都是**整份 doc**，`/sop-init` 只在 slot 处 find/replace、**绝不在 doc 中段动刀** → freshness 这类载重位置结构上埋不了。**增量时（F8）**：整份 copy 只对**新增的层**；已存在的层（owner 已填槽 / 有正当宽放）退回**块/槽级补缺**、不整份重 copy（否则砸掉填好的内容）。

## 6. `/sop-init` 新流程

1. 读 `STANDARD.md §1`（公约权威，不重抄）
2. 定参数（ends / collaborators / risk / house_style；能从代码推断就推断，推不了一次问清）
3. **右尺寸校验**（反驳在此发力：多端/多人结构是真有还是预建？真一次性脚本 → 建议别 init）
4. **copy `base/` 整份 → 填槽**
5. **按三触发各 copy 对应 layer 整份**（≥2人→collaborators；≥2端→multiend + 每端CLAUDE.md；并行→parallel-agents）。没触发不 copy（右尺寸硬约束）
6. **增量幂等**：已有 SOP 只补缺的那层、不砸已有（§3.5）
7. 报告 + 便宜验证（owner 扫 CLAUDE.md + 目录树即可验收）

## 7. `/sop-audit` 改成双向 diff（exp-013 根治；exp-010 只减负、不根治）

> ⚠️ 自检修正：只 `stale` 方向（项目留着 master 已删的块）是真·机械逮 = exp-013 根治。`missing` 方向（项目缺护栏）仍要 exp-010「近似≠覆盖」那套语义 LLM 读，**没机械化**。且 diff 必须 **layer-gated（只比触发命中的层，剪掉的层不算 missing）+ slot-masked（槽是洞、不参与比）**，否则填好的槽 / 正当宽放 / 正确剪掉的层全被误报。剩下区分仍是语义判，诚实标。

| 维度 | 老 baseline | 新 baseline |
|---|---|---|
| 对照物 | STANDARD 抽象正文（语义判，会漏） | **项目 doc ↔ `master/` 对应 layer 当前版**（具体↔具体） |
| 增方向 | 近似≠覆盖靠 LLM 读 | 项目缺 master 有的护栏 = `missing`（机械） |
| 删方向 | **盲**（exp-013） | 项目留 master 已删的块/档 = `stale`（机械逮，如残留 S1·C1） |
| 母本保鲜 | 无 | **一次性 bootstrap**：从 media-ops/taoxi-geo 抠出 `master/` 后，它俩**翻成 master/ 的下游消费者**——跟其它项目一样跑 `/sop-audit`（机械 diff），不需要单独的"master↔真仓"保鲜机制。它俩日后长出的护栏经**回灌**进 master/ |
| 本地偏离 | — | 正当本地偏离照旧**宽放**（右尺寸，不报；§5.1 防过度治理不破） |

> 诚实修正：早先说"母本↔真仓机械 diff"是overstate——`master/base` 是 media-ops 清洗+解构后的派生物，跟它**不是逐字一致**，那个方向的 diff 是语义的。所以不另设保鲜机制：bootstrap 后 media-ops/taoxi-geo 当下游项目审（机械），唯一真·语义边界只剩 §1↔master/（见 §10），靠保真清单 + 回灌兜。

audit 头号仍是"过度治理"，其余维度（结构错配/沟通约束塌口号/结构缺失/凭据失真）保留；漂移检查的 `stale` 方向机械（`missing` 仍语义）——且这套**双向 diff 已 ship**（`sop-audit:28`），本次只把它**接到 master/** + layer-gated/slot-masked。

## 8. 🧱 承重墙保真清单（exp-006 雷区 · make-or-break · 强制 + 新眼睛）

搬迁/蒸馏最容易在"摘要版"丢安全网。实施第 1 步**必须**：

- 建映射表：**STANDARD §1 每条 + 每个 exp-NNN carve-out（全列、不手挑 · F6）**——004缺上游 / **005反向验收+净增上限** / **006瘦内核+承重墙不豁免行** / 007决策闸 / 008立栈 / 009 escalate / 011说人话闸（黑话/结论先行/大段 + **受众carve-out**）/ 012挂对闸 / 013双向diff → 兑现在 `master/` 哪个文件哪行。
- **判据是逐条 text-equivalence、不是 topic-presence（F6）**：不是"说人话提到了 = 过"，而是拿**当前权威版**（STANDARD §1 与 templates/ 取较新者）逐字比；新眼睛带**子闸清单**（6 反驳闸 A–F / 黑话闸·结论先行闸·大段闸·受众carve-out / 承重墙不豁免行）**逐个 verbatim 核**——降级版 = 丢。
- **指针不悬空（F10）**：重排 templates/ 后，STANDARD §1.7/§1.8/§4 + 两个 SKILL 里"权威闸在 templates/…"全部重指到 master/；其中 §1.7 那处是**"§1 不动"的唯一例外**，单独登记。（实施前让新眼睛**重 grep `templates/` 引用**、别照本清单——它先前就把不存在的 §5.5 写错过。）
- **挂对闸（exp-012 形状 · 比"文字在场"更要紧）**：重排 = 把护栏**在层间搬家**，正是 exp-012 出事的动作。每条搬动的护栏，新眼睛必须**点名一个真实项目类**（单人多端并行=taoxi-geo / 2人单端串行=media-ops / 多端串行）确认它仍**经对的触发够得着**——text-equivalence 查不出"文字对、挂错闸"。
- 派**独立新眼睛子代理逐条撞**（exp-006：减法/搬迁比加法更要新眼睛）。
- **双向反向验收**（exp-005/006）：① master 没丢任何护栏（含降级版 = 丢）；② 搬迁没偷加新 covenant（**STANDARD §1 净变 ≈ 0** + §2-5 改写设**净增行数上限** · grep 反向验收没混进新概念 · exp-005）。
