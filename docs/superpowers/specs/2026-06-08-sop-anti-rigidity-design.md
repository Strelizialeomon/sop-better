# Spec:防 SOP 僵化——元规则 + 反向齿轮 + 瘦内核(A+B)

> 状态:待 owner review。走本项目工作流(STANDARD §1.3):跳 writing-plans,spec 带**可检验验收**,build 后派**独立新眼睛 review**,记 `exp-006`。

---

## 1. 要解决什么

owner 担心:SOP 一轮轮迭代,规则越攒越多 → 压垮 agent 的想象力、把体系搞僵;但 SOP 又不能没有(没它没法跟业务协作)。

**实测(本会话末)**:STANDARD 149 行(vs taoxi-geo 反面教材 829,才 ~18%),本会话净增仅 +10 行 —— **绝对体量没爆**。但有两个**僵化早期信号**:
- **always-loaded 约束块 = 10 条 bullet / ~1330 字**:每 token 怼脸 → 把 agent 从"思考"压成"打勾"。← 主病灶
- §1.8 单条 865 字(项目自己的"行数=信号"在喊)。

**根因**:这台机器只有"加挡"(每条规则有 exp 反例背书)、**没有"减挡"**(从不删/合/降级)→ 个个对 + 永不删 = 必成笼子。

## 2. 设计(三件,合 better-lighter)

### A1 · 元规则:地板不是天花板(发"想象力许可证")
STANDARD §1 顶 + 约束块顶各一句:
> 这些规则是**安全地板、不是思考天花板**。照字面会让结果变差 / 情况没覆盖 → **用判断按精神来 + 标记一句(不静默跳过)**,owner 终裁。

- 许可的是"按精神 + **标记**",不是"静默忽略" → 解开规则机器人心态,又不破坏安全网(反驳 / 凭据保真 / 不擅自 push 仍是硬地板)。

### A2 · 反向齿轮:让机器会"减挡"
- **STANDARD §3.5**(现仅"规则按需长")补对称一句:**规则也按需删 / 合 / 降级——加一条前先查能否并进已有;`/sop-audit` 或自审时查"从没触发 / 被别条 subsume / 已内化"的死规则 → 删之。SOP 允许掉秤。**
- **sop-audit** 加一只眼:审项目时,**约束块里 agent 从不照做 / 与别条重复的规则 → 按过度治理报出、建议删合**(同它头号查的那把尺)。

### B · 瘦内核:always-loaded 块 10 条 → 5 条 + 1 指针
情景规则(开工 / gh / 形态细节 / 取活)**不删,挪到"到那个场景才读"的文档**(它们本就在 issue-pr-workflow / collaboration / §1.2 里)。新内核:

```markdown
## Agent 工作约束(本项目 · {{SC}})
> 安全地板,不是思考天花板:照字面会变差 / 没覆盖 → 按精神判 + 标记,owner 终裁。

- 分工:你定「要什么」(目标/约束/验收/产品形态——用你懂的话、别默认命令行)+ 否决权;
  我定「怎么做」(架构/解法我提案、你评审)。起手先确认你是业务还是开发(默认业务)。
- 敢顶 + 照亮不代选:先反方后结论、标信心、不空夸;补盲区列权衡,但不替你拍板。(细则见沟通约束块)
- 自决不阻塞,但缺上游交付物反弹不自补:局部直接改;涟漪/跨界/重做才找你;
  别人该给的 doc/需求/契约缺了 → 反弹 + 标待澄清,绝不脑补。
- 撒手有安全网:跳 writing-plans,代价是 spec 验收「可检验」+ 必过「独立新眼睛 review」;
  默认撒手档 = {{default_altitude}},高风险升回你。
- (C≥C1)情景规则按需读、别都怼这:起手(sync+扫待你确认的 issue+gh 就绪)、接活(先判细化)、
  收工(推收口 doc)、跨端契约… → 到那场景再读 issue-pr-workflow.md / collaboration.md(C0 无此环节,跳过)。
（再附沟通约束块)
```

- **10 条合 5 条**:把 role-ask/形态 并进「分工」、主动建议并进「敢顶」、writing-plans/code-review/撒手档并进「安全网」;开工/gh/收工/取活 收进第 5 条指针。
- **C0 防悬空**:第 5 条标 `(C≥C1)` —— S1·C0 用标准块但无 workflow 文档,标了就跳过、指针不悬空。

## 3. 明确不做(防"用过度治理治过度治理")

- ❌ **不动沟通约束块**(反驳 6 闸 + 说人话 4):它是撒手承重墙、且每轮行为都要在脸上,压缩风险 > 收益。要瘦它以后单议。
- ❌ **不删情景规则**:只从 always-loaded 块**挪走**(它们在 on-demand 文档里仍各有唯一一份),不是删功能。
- ❌ 不新立章节 / 不重抄:A1/A2 是给 §1、§3.5 加句;B 是**净删**约束块内容 + 合并。
