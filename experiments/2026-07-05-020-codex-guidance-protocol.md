## 4. AI 跑完,我来评

- **AI 做了哪些决策**(它替我想的部分):
  - 把协议定为“覆盖所有任务,但不阻塞所有任务”。
  - 用动作后果分层,而不是按用户有没有说“直接做”分层。
  - 把低风险局部补丁 carve-out 写进规则,避免确认疲劳。
  - 把 audit 查法扩到“三层引导缺失 / 过度阻塞”。
- **超出我预期 / 我自己想不到的地方**(← 爽感来源,最重要):
  - 新眼睛审 spec 时抓到首版“所有本地编辑都阻塞”会冲突 `局部补丁 → 直接改`,这个反向校准比直接加规则更关键。
  - “导航卡不一定 2-3 选项;没真分叉只给 1 个下一步或明确结束”能避免假选择。
- **翻车 / 我得纠偏的地方**:
  - 三层协议仍可能被未来 agent 写成表演式菜单;需要 audit 继续查“假选择”和“过度阻塞”。
