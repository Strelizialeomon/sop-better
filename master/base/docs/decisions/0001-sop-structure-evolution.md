# ADR-0001: 开发 SOP 随项目现实演进

- **日期**:{{initialized_on}}
- **状态**:已采纳

## 背景

{{project_name}} 需要可追踪、可恢复的开发约定，但不为尚未出现的人、端或并行形态预建设施。

## 决策

- 所有项目保留核心 AGENTS、ADR 与 issue + PR 工作流。
- 出现第 2 位真人协作者时，增加业务与开发 handoff。
- 出现第 2 个端时，增加跨端契约和每端 AGENTS 操作台。
- 多端进入真并行多 agent 时，才增加物理隔离和协调骨架。
- Git 基线来自 profile；本项目当前是 `origin/{{default_branch}}`。

## 影响与反转条件

结构只在触发成立时增加。项目形态变化后重跑生成器，先看 diff，再确认 render；不得用旧 ADR 当成跳过确认的授权。
